# 2026 부산 락 페스티벌

부산 락 페스티벌 행사 홍보 웹페이지입니다. HTML, CSS 및 티켓 선택 기능을 하나의 HTML 파일에 담았습니다.

- 원본 웹페이지: `event_homepage.html`
- GitHub Pages 진입 파일: `index.html` (원본과 동일한 내용)
- 공개되지 않은 행사 정보: “추후 공지” 표시
- 티켓 선택 시 권종과 참가비를 표시합니다. 실제 예매 링크는 추후 공지입니다.

원본을 수정하면 `index.html`에도 같은 내용을 반영해야 합니다. GitHub Pages는 `main` 브랜치의 루트 폴더에서 배포합니다.
